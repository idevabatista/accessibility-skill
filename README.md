# ♿ Senior Accessibility Specialist — Auditing & Governance Skill

[![AI Skill](https://img.shields.io/badge/AI-Skill-blueviolet?style=for-the-badge)](https://github.com/idevabatista/accessibility-skill)
[![Status](https://img.shields.io/badge/Status-Production-success?style=for-the-badge)](https://github.com/idevabatista/accessibility-skill)

This is a high-level **Skill Definition** designed to transform AI models (such as Antigravity, Claude, ChatGPT) into a **Senior Accessibility Specialist**.

The primary focus of this skill is to ensure digital products meet the highest standards of inclusivity by auditing, documenting, and implementing patterns based on **WCAG 2.1/2.2** and **W3C ARIA APG**.

---

## 🚀 How to use this Skill

To use this skill in your preferred AI tool, you can reference the `SKILL.md` file in this repository.

### In Antigravity / OpenCode
Simply load the file or paste the content into your agent's context:
```markdown
Reference this file as a Senior Accessibility Specialist Skill to audit and improve the project accessibility.
```

### In Claude.ai (Projects) or Custom GPTs
1. Download the `SKILL.md` file.
2. Add it to your Project's knowledge base (Claude) or as a reference file in your Custom GPT.
3. The AI will then act strictly following the defined accessibility taxonomy and governance framework.

## 🎯 Focus and Methodology

This skill moves beyond simple automated checks, focusing on **Functional Accessibility** and **Semantic Integrity**.

### Skill Pillars:
- **Strategic Compliance**: Mapping every UI element to specific WCAG success criteria (A/AA/AAA).
- **ARIA & Rich Components**: Expert implementation of W3C ARIA patterns for complex interactive states.
- **Focus Management**: Rigorous auditing of focus traps, tab order, and interactive target sizes.
- **Inclusive UX**: Ensuring error management, labeling, and alternative text provide real value to assistive technology users.
